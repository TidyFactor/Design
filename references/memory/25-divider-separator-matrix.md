# 25 · Section Transitions & Dividers Library (Volume 03)
<!-- last-verified: 2026-09-05 -->

> GSAP ScrollTrigger + SVG-native seam system — Volume 03 of the design system. Inherits utilities from the Hero Library (`prepDraw`, `depthParallax`, reduced-motion guard).

The boundary between two sections is where pages expose whether they were **assembled** or **authored**. This library treats every seam as a designed surface with its own geometry, motion behavior, and ownership.

---

## 1. Boundary Anatomy — The Mental Model

Every transition has 4 layers. Get the ownership rule right and everything else follows:

```
┌─────────────────────────────┐
│  ① Outgoing Surface         │  previous section (its bg shows behind the seam)
├─────────────────────────────┤
│  ② Seam Geometry            │  the divider path — THIS LIBRARY
├─────────────────────────────┤
│  ③ Motion Behavior          │  static | scrub | pin
├─────────────────────────────┤
│  ④ Incoming Surface         │  next section
└─────────────────────────────┘
```

> **Core rule:** The seam always belongs to the **incoming** section — filled with *its* background color, drawn in *its* geometry. A divider is that section's first impression.

## 3. Shared Foundation

### 3.1 — Global Divider CSS (apply to every seam)

```css
.divider {
  display: block;               /* kills inline-gap */
  width: 100%;
  height: clamp(56px, 9vw, 130px);
  margin-bottom: -1px;          /* kills sub-pixel hairline seam */
}

/* Direction tokens */
[data-flip-v] .divider { transform: scaleY(-1); }   /* wave crests downward */
[data-flip-h] .divider { transform: scaleX(-1); }   /* mirror diagonal */
```

### 3.2 — Parametric Wave Generator (the library's engine)

```js
/**
 * Generates a filled wave path.
 * Same `cycles` → identical command structure → GSAP can morph between any two.
 */
function wavePath({ w = 1440, h = 120, cycles = 2, amp = 38, phase = 0 } = {}) {
  const mid = h / 2;
  const seg = w / cycles;
  let d = `M0 ${mid}`;
  for (let i = 0; i < cycles; i++) {
    const x = i * seg;
    const peak = mid + ((i + phase) % 2 ? amp : -amp);
    d += ` C ${(x + seg * 0.36).toFixed(1)} ${peak}, ${(x + seg * 0.64).toFixed(1)} ${peak}, ${x + seg} ${mid}`;
  }
  return `${d} L${w} ${h} L0 ${h} Z`;
}
```

**Design consequence:** waves are now **tokens, not artwork** — `amp`, `cycles`, `phase` are themeable values, and AI can generate unlimited variants from one function.

## 4. Components

### Family A — Static Topology (zero JS, maximum reliability)

### 01 · Parametric Wave Divider
**Concept:** The signature soft seam. Generated by the engine above — the default divider of the system.

```html
<section class="section" style="--bg: #0f172a" data-divider="wave">
  <svg class="divider" viewBox="0 0 1440 120" preserveAspectRatio="none" aria-hidden="true">
    <path data-wave fill="var(--bg)"/>
  </svg>
  <!-- section content -->
</section>
```

```js
function waveDivider(scope) {
  scope.querySelectorAll('[data-wave]').forEach(p =>
    p.setAttribute('d', wavePath({ cycles: 2, amp: 38 })));
}
```

**Detailing:** `preserveAspectRatio="none"` stretches to any viewport; `height` clamp controls visual amplitude — never redraw for breakpoints.  
**Fill = incoming `--bg`** (ownership rule).

---

### 02 · Diagonal Cut Divider
**Concept:** Angular editorial cut. The polygon self-adjusts its angle to viewport width — no media queries.

```html
<svg class="divider" viewBox="0 0 1440 120" preserveAspectRatio="none" aria-hidden="true">
  <polygon points="0,120 1440,0 1440,120" fill="var(--bg)"/>
</svg>
```

- **Reverse direction:** wrap with `data-flip-h`
- **Steepness token:** change `h` in viewBox (`60` = subtle, `200` = aggressive)
- **Pairs with:** Hard-Edge Tag · Left Border Accent eyebrows

---

### 03 · Corner Notch Section
**Concept:** A "cut corner" clipped into the incoming section — brutalist, architectural, container-as-transition.

```css
.section--notch {
  --notch: 72px;
  clip-path: polygon(
    0 0,
    calc(100% - var(--notch)) 0,
    100% var(--notch),
    100% 100%,
    0 100%
  );
}
```

- **Requirement:** the page wrapper behind needs a contrasting bg — the notch reveals *it*, not the previous section directly
- **Variant:** notch both top corners (`--notch` on both sides) for a "tab" silhouette
- **Pairs with:** Hard-Edge Tag · Monospace Annotation

---

### 04 · Scallop Perforation
**Concept:** Ticket-style punched edge — pure CSS, no SVG. Reads as "crafted packaging."

```css
.scallop-seam {
  height: 12px;
  background: radial-gradient(
    circle at 50% 0,
    var(--bg-prev) 6px,      /* punch radius */
    var(--bg-next) 6.5px     /* 0.5px anti-alias ring */
  );
  background-size: 16px 12px; /* scallop density token */
}
```

- Placed as the **first child** of the incoming section
- **Detailing:** the `0.5px` second stop is the anti-aliasing trick — without it, edges alias badly on non-retina
- **Pairs with:** Rotating Stamp Seal · Highlight Marker

### Family B — Scroll-Reactive (scrub-driven)

### 05 · Morphing Wave
**Concept:** The wave **reshapes itself** as it scrolls into view — geometry as a scrub timeline. Only possible because the generator guarantees identical command structure.

```html
<svg class="divider" viewBox="0 0 1440 120" preserveAspectRatio="none" aria-hidden="true">
  <path data-morph-wave fill="var(--bg)"/>
</svg>
```

```js
function morphWave(scope) {
  const path = scope.querySelector('[data-morph-wave]');
  const from = wavePath({ cycles: 2, amp: 22, phase: 0 });
  const to   = wavePath({ cycles: 2, amp: 52, phase: 1 });

  gsap.fromTo(path, { attr: { d: from } }, {
    attr: { d: to },
    ease: 'none',
    scrollTrigger: { trigger: scope, start: 'top bottom', end: 'top 40%', scrub: 0.6 }
  });
}
```

**Critical constraint:** morphing requires **identical command counts** — always tween between paths generated with the same `cycles`. Different `cycles` = broken interpolation, not an error.  
**Detailing:** `phase: 1` flips crest/trough, so the wave visibly *inverts* while growing — higher perceived motion than amp alone.

### 06 · Draw-On Seam
**Concept:** A dashed technical line stitches itself across the boundary; milestone nodes pop as the line passes them. Inherits `prepDraw` from the Hero Library.

```html
<svg class="divider" viewBox="0 0 1440 80" aria-hidden="true">
  <path data-draw
        d="M0 40 C 240 18, 480 62, 720 40 S 1200 18, 1440 40"
        fill="none" stroke="currentColor" stroke-width="2"
        stroke-dasharray="8 8" stroke-linecap="round"/>
  <circle class="seam__node" cx="720"  cy="40" r="6"/>
  <circle class="seam__node" cx="1440" cy="40" r="6"/>
</svg>
```

```js
function seamDraw(scope) {
  prepDraw(scope); // inherited utility — Hero Library
  gsap.timeline({
    scrollTrigger: { trigger: scope, start: 'top 85%', end: 'top 25%', scrub: 0.5 }
  })
  .to(scope.querySelectorAll('[data-draw]'), { strokeDashoffset: 0, ease: 'none' })
  .from(scope.querySelectorAll('.seam__node'),
    { scale: 0, transformOrigin: 'center', stagger: 0.2 }, '<0.2');
}
```

**Pairs with:** Blueprint Wireframe Hero — the seam becomes a *continuation* of the hero's drawing language.

### 07 · Rising Edge Wipe
**Concept:** The incoming section rises as a **rounded card** and flattens as it docks — the mobile-sheet metaphor, at section scale.

```js
function risingEdge(section) {
  gsap.fromTo(section,
    { clipPath: 'inset(14% 4% 0% 4% round 28px)' },
    {
      clipPath: 'inset(0% 0% 0% 0% round 0px)',
      ease: 'none',
      scrollTrigger: { trigger: section, start: 'top bottom', end: 'top 20%', scrub: 0.5 }
    }
  );
}
```

**Detailing insight:** the corner **radius collapsing to 0** at dock is the moment that sells it — the section "locks in."  
**Caution:** `clip-path` scrub forces repaint on a large surface — use on **1–2 boundaries per page**, not all.  
**Fallback:** `border-radius` + negative margin static version under `prefers-reduced-motion`.

---

### 08 · Scaling Crest
**Concept:** The wave unfolds from a flat baseline — terrain rising. Cheapest possible motion, surprisingly strong payoff.

```js
function crestRise(scope) {
  gsap.from(scope.querySelector('.divider'), {
    scaleY: 0.08,
    opacity: 0.4,
    transformOrigin: 'bottom center',
    duration: 1.1,
    ease: 'expo.out',
    scrollTrigger: { trigger: scope, start: 'top 75%', once: true }
  });
}
```

- `once: true` — one-shot, zero scroll cost afterward
- `transformOrigin: bottom` = grows **upward** from the seam line
- **Pairs with:** Kinetic Split-Type Hero (same `expo.out` language)

### Family C — Layer Overlap (structural)

### 09 · Sticky Overlap Stack
**Concept:** Sections are physical sheets — each new one slides **over** the previous, which recedes with scale + fade. Depth without a single pin.

```html
<main class="stack">
  <section class="panel" style="--bg:#0f172a"><div class="panel__inner">…</div></section>
  <section class="panel" style="--bg:#1e293b"><div class="panel__inner">…</div></section>
  <section class="panel" style="--bg:#312e81"><div class="panel__inner">…</div></section>
</main>
```

```css
.panel { position: sticky; top: 0; min-height: 100vh; background: var(--bg); }
```

```js
function stackDepth(panels) {
  panels.forEach((panel, i) => {
    const next = panels[i + 1];
    if (!next) return;
    gsap.to(panel.querySelector('.panel__inner'), {
      scale: 0.92, opacity: 0.45, transformOrigin: '50% 0%',
      ease: 'none',
      scrollTrigger: { trigger: next, start: 'top bottom', end: 'top top', scrub: true }
    });
  });
}
```

**Critical detail:** scale the **`.panel__inner`**, never `.panel` — transforming a sticky element breaks its pinning math.  
**Graceful degradation:** the overlap works with **CSS only**; the scale/fade is enhancement. This is the most resilient premium transition in the library.  
**Pairs with:** Pinned Horizontal Hero (same physical-object narrative).

---

### 10 · Curtain Split Wipe
**Concept:** A pinned boundary zone where two panels split apart like theater curtains — the page performs its own scene change.

```html
<div class="curtain" style="--bg-prev:#0f172a; --bg-next:#1e1b4b">
  <div class="curtain__panel curtain__panel--l" aria-hidden="true"></div>
  <div class="curtain__panel curtain__panel--r" aria-hidden="true"></div>
</div>
```

```css
.curtain { position: relative; height: 100vh; background: var(--bg-next); overflow: hidden; }
.curtain__panel { position: absolute; inset: 0; width: 50.5%; background: var(--bg-prev); will-change: transform; }
.curtain__panel--l { left: 0; }
.curtain__panel--r { right: 0; }
```

```js
function curtainWipe(scope) {
  gsap.timeline({
    scrollTrigger: { trigger: scope, start: 'top top', end: '+=100%', pin: true, scrub: 0.6 }
  })
  .to('.curtain__panel--l', { xPercent: -102, ease: 'power2.in' }, 0)
  .to('.curtain__panel--r', { xPercent:  102, ease: 'power2.in' }, 0);
}
```

**Detailing:** panels are `50.5%` wide — the 0.5% overlap kills the center hairline during the split. `power2.in` = accelerating exit feels like release, not sliding.  
**Budget:** this is the heaviest component — **max one per page**, and it's the page's "loud transition."

### Family D — Atmospheric & Editorial

### 11 · Color-Field Crossfade
**Concept:** No geometry at all — the page's background **morphs between section palettes** as you cross thresholds. The seam becomes atmosphere.

```html
<section data-bg="#0f172a">…</section>
<section data-bg="#1e1b4b">…</section>
<section data-bg="#052e16">…</section>
```

```js
function colorCrossfade(sections = '[data-bg]', target = document.body) {
  gsap.utils.toArray(sections).forEach(section => {
    ScrollTrigger.create({
      trigger: section, start: 'top 55%', end: 'bottom 55%',
      onToggle: self => self.isActive && gsap.to(target, {
        backgroundColor: section.dataset.bg,
        duration: 0.7, ease: 'power2.out', overwrite: 'auto'
      })
    });
  });
}
```

**Why `onToggle` + `isActive`:** one handler covers both scroll directions — no duplicated `onEnter`/`onEnterBack` logic.  
**Critical:** text contrast must hold **at every point** of the fade, not just endpoints — pick palettes with similar luminance ranges.  
**Combine freely** with any Family A divider: geometry + atmosphere stack cleanly.

### 12 · Rule + Index Divider
**Concept:** Editorial seam — a hairline blooms outward from a section number. Zero SVG, pure typography. Connects to the **Numbered Editorial Index** eyebrow.

```html
<div class="rule-index" data-rule-index>
  <span class="rule-index__line" aria-hidden="true"></span>
  <span class="rule-index__num">02</span>
  <span class="rule-index__line" aria-hidden="true"></span>
</div>
```

```css
.rule-index { display: flex; align-items: center; gap: 20px; max-width: 640px; margin: 96px auto 48px; }
.rule-index__line { flex: 1; height: 1px; background: currentColor; opacity: 0.25; }
.rule-index__num { font-variant-numeric: tabular-nums; font-size: 13px; letter-spacing: 0.1em; }
```

```js
function ruleIndex(scope) {
  const el = scope.querySelector('[data-rule-index]');
  gsap.timeline({ scrollTrigger: { trigger: el, start: 'top 85%', once: true } })
    .from(el.querySelectorAll('.rule-index__line'), {
      scaleX: 0, duration: 0.9, stagger: 0.12, ease: 'power3.out',
      transformOrigin: (i) => i === 0 ? 'right center' : 'left center' // bloom outward
    })
    .from(el.querySelector('.rule-index__num'), { opacity: 0, y: 8, duration: 0.5 }, '-=0.5');
}
```

**Detailing:** both lines grow **away from** the number — a "bloom," not a wipe. Small distinction, outsized perceived quality.

## 5. Composition Recipes

| Recipe | Seam Stack | Hero Pairing | Eyebrow Pairing |
|--------|-----------|--------------|-----------------|
| **SaaS Launch** | 08 Crest → 11 Crossfade | Kinetic + Aurora Grain | Status Dot |
| **Dev Tool** | 06 Draw-On Seam (dashed, continuous from hero) | Blueprint Wireframe | Monospace Annotation |
| **Agency Portfolio** | 09 Sticky Stack → 10 Curtain (finale) | Text-Mask Scene | Hand-Drawn Accent |
| **Editorial / Report** | 12 Rule+Index between every section | Kinetic Split-Type | Numbered Index |
| **E-commerce** | 04 Scallop → 02 Diagonal | Organic Blob | Stamp Seal |
| **Enterprise B2B** | 01 Wave + 11 Crossfade only | Aurora Grain | Ghost Chip |

> **Energy budget rule:** one **loud** transition per page (Curtain, Stack, Rising Edge). Everything else stays **quiet** (Wave, Rule, Crossfade). A page where every seam performs has no seams at all — just noise.

## 6. Token Schema (for AI generation)

```yaml
section_transition:
  seam:
    type: wave | diagonal | notch | scallop | none
    params: { amp: 22–60, cycles: 1–4, phase: 0|1, notch: 48–96px }
    ownership: incoming-section
    fill: "{section.bg}"
  motion:
    behavior: static | scrub | once | pin | toggle-tween
    trigger: "top bottom → top 20–40%"
    scrub_lerp: 0.5–0.6
    loud: false   # max ONE true per page
  atmosphere:
    bg_morph: { enabled, palette: [lum-similar colors] }
  a11y:
    decorative: aria-hidden
    reduced_motion: static-geometry, no-scrub, sticky-stack-native
  perf:
    clip_scrub_limit: 2-boundaries
    pin_limit: 1-per-page
    css_only_first: true
```

## 7. Checklists

**Performance**
- [x] Family A components are **zero-JS** — always prefer them when motion isn't essential
- [x] `scrub: 0.5–0.6` lerped on all seam scrubs
- [x] Max **1 pin** (Curtain) + **2 clip-path scrubs** (Rising Edge) per page
- [x] `will-change: transform` on curtain panels only — nothing else
- [x] `margin-bottom: -1px` on every SVG divider — sub-pixel seams are the #1 "AI-built page" tell

**A11y**
- [x] All dividers/seams → `aria-hidden="true"` (pure decoration, zero semantics)
- [x] `prefers-reduced-motion` → geometry renders static at final state; Sticky Stack keeps working (CSS-native); Curtain falls back to a simple color boundary
- [x] Crossfade palettes: verify contrast mid-fade, not just at endpoints
- [x] No seam animation ever delays content readability — text sections must be legible even if ALL motion fails

---

> **Pro rule:** Geometry is permanent, motion is seasoning. Design every seam to look correct **as a static image first** — then let ScrollTrigger decide how it arrives. A divider that only works in motion is a bug that happens to look good.
